First release of **Nspire Studio**: make notes for your TI-Nspire CX / CX II on your computer and send them over USB.

- Tabs, text, headings, typeset LaTeX equations, images and graphs
- Live input/output calculators that use the calculator's own math engine
- A pixel-accurate live calculator view, a file browser and screenshots

### Downloads
| System | File |
|---|---|
| Fedora 44+ | `nspire-studio-*.x86_64.rpm`: `sudo dnf install ./nspire-studio-*.rpm` |
| Debian 13+ / Ubuntu 25.04+ | `nspire-studio_*_amd64.deb`: `sudo apt install ./nspire-studio_*.deb` |
| Windows 10/11 | `NspireStudio-*-Setup.exe` (installer) or `NspireStudio-*-Windows-portable.zip` |

**Windows:** the calculator needs the WinUSB driver (one-time, using Zadig). See [Windows USB driver](https://github.com/ezeren76neptune/nspire-studio#windows-usb-driver) in the README.
